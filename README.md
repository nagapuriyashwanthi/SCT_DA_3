# SCT_DA_3 - Interactive Visualization

## 📌 Task Overview
Built an interactive HR Attrition Dashboard 
using Power BI as part of my Data Analyst 
Internship at SkillCraft Technology.

## 🛠️ Tools Used
- Microsoft Power BI Desktop

## 📊 Dataset
- IBM HR Employee Attrition Dataset
- 1,470 rows and 35 columns

## ✅ What I Did
- Loaded HR Attrition dataset into Power BI
- Created Card visual (Total Employees)
- Created Bar Chart (Attrition by Department)
- Created Column Chart (Attrition by Age Group)
- Created Bar Chart (Attrition by Job Role)
- Added interactive Slicers (Department, Age, Gender)
- Built professional Dashboard

## 📈 Key Insights
- R&D Department has highest attrition
- Age group 25-34 leaves most
- Lab Technicians resign most often
- Overall attrition rate is 16%

## 💡 Key Learnings
- How to use Power BI Desktop
- How to create interactive visuals
- How to add slicers and filters
- How to build professional dashboards
